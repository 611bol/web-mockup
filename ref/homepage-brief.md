# 611 新網站首頁 Brief（給 /impeccable shape）

更新日期：2026-11-03（第 7 版）

## 1. 目標與受眾

| 項目 | 內容 |
|---|---|
| 目標 | 簡化選單與首頁，讓使用者快速找到要看的內容 |
| 主要受眾 | 會友、小組長、分堂同工（看直播、晨禱、講道）；新朋友（認識教會、第一次來訪） |
| 審核對象 | 牧者與同工 |
| 參考 | elevationchurch.org（首頁 hero 輪播 2 張：歡迎影片、最新講道）、kingdomcity.com |

## 2. 固定限制

- 語言：繁體中文為主，核心頁面提供中、英、日三語；沒有日文版的頁面在日文介面不顯示。日文版是給日本分堂。
- 沒有預約來訪功能：新朋友在現場填寫資料，網站不放「預約來訪」按鈕，只提供資訊。
- 品牌色以 `611 logo color code.jpeg` 為準，不更動。
- 正式站技術：Payload 3 CMS（跑在 Next.js 上）+ Astro SSR 公開網站（見 `website-revamp` 的 `docs/architect.md`，目前為 proposal）。
- Mockup 技術：純靜態 HTML/CSS，只用少量原生 JS，部署在 GitHub Pages。顏色與字型用 CSS 變數，元件用純 HTML，方便之後移植到 Astro。這是給牧者與同工審閱的設計與結構提案，不是正式版。
- Mockup 要證明：首頁層級可行（2 張 hero、直播選台、14 天晨禱加講道）；新朋友有清楚路線且只提供資訊；7 項選單比現在的 13 項簡單；手機版可用（含 hero 影片改為海報圖）；直播中、倒數、回放三種狀態看得清楚（用範例資料做成可切換的示範）。
- Mockup 不需要證明：真正的直播串流、CMS 編輯、語言切換邏輯。
- 字型建議：Noto Sans TC（內文）、Noto Serif TC（標題）；行高要適合中文。
- 手機優先，並考慮長者使用（對比度、點擊範圍）。

## 5. Hero 輪播（區塊 1）

### 第 ① 張：歡迎新朋友（影片背景）

| 項目 | 內容 |
|---|---|
| 內容 | 歡迎標題與一兩句話，背景是歡迎影片 |
| 按鈕 | 第一次來訪（→ 第一次來訪頁：時間、地點、交通、報到方式）、認識611（→ 關於我們） |

**影片處理**

| 項目 | 做法 |
|---|---|
| 影片來源 | 教會預備；放在 CMS 媒體庫 |
| 播放方式 | 桌面版：靜音、循環、自動播放，只當背景，沒有播放按鈕，也不需要字幕 |
| 手機版 | 不自動播放，改為靜態海報圖 |
| 省流量、系統設定為減少動態效果 | 同手機版，顯示靜態海報圖 |
| 影片內容 | 因為靜音又沒有字幕，影片不能靠語音傳達訊息，訊息由標題與按鈕負責 |
| 檔案 | 建議 10 至 20 秒、盡量壓縮；每支影片都要附一張海報圖 |
| 文字可讀性 | 影片上加暗色漸層，確保標題與兩個按鈕對比足夠 |
| 輪播切換 | 切到第 ② 張時，第 ① 張的影片暫停 |

### 第 ② 張：最新一次崇拜

內容：標題、講員、日期、語言。按鈕依狀態切換：

| 狀態 | 狀態標示 | 主按鈕 | 次按鈕 |
|---|---|---|---|
| 直播中 | 🔴直播中 | 立即觀看（跳到下方直播選台區的播放器） | 更多崇拜內容（→ /watch） |
| 非直播 | 無 | 觀看整場崇拜（→ 該場崇拜的講道頁） | 更多崇拜內容（→ /watch） |

### 輪播規則

- 只放這 2 張，不加活動海報。活動海報留在區塊 4。
- 文字用網頁文字呈現，不畫在圖上；圖片補替代文字。
- 有圓點與左右箭頭手動切換；自動輪播要慢，滑鼠停留或鍵盤聚焦時暫停。
- Hero 高度要克制，讓首屏底部看得到直播選台區的上緣，不要把直播推到要捲動才看得到。

## 6. 直播選台區（區塊 2）

概念：像選台一樣，使用者選擇要看的崇拜或系列節目。這是現有網站的優點，整體版面與互動方式沿用。

**必須保留的既有功能**

| 功能 | 位置 |
|---|---|
| 直播中標示 | 右側時間表（🔴現場直播 LIVE） |
| 倒數計時 | 播放器上，以及播放器下方頻道標籤 |
| 右側時間表預設收合 | 固定高度，約顯示前 8 項，底部箭頭展開；收合時與播放器等高，沒有多餘空白 |
| 頻道標籤列 | 播放器正下方，與播放器同寬 |

**調整（僅限內容整理，不改版面結構）**

| 項目 | 做法 |
|---|---|
| 頻道列 | 5 至 6 個：晨禱、主日崇拜、跟隨神、Gen TOL、敬拜、更多（連到 /watch）。要看得出可以左右滑（現有版本最後一個標籤被切掉）。 |
| 右側時間表 | 按時間排序，直播中置頂。廣告類影片由教會從來源移除，設計不需處理廣告項目。 |
| 標題語言 | 依語言切換顯示，不再中英並排。 |
| 標題顏色 | 時間表標題目前全部粉紅色粗體；只用強調色標示直播中，其餘用一般文字色。 |
| 講道筆記 | 分頁維持；另在主日講道頁提供完整版。 |
| 晨禱重播 | 依語言切換：粵語／普通話（音訊加 YouTube）、英文、Tagalog、Bahasa Indonesia、Español。直播同時有粵語與普通話。 |
| 手機版 | 時間表維持收合，點開展開，不並排。 |
